### 3.2 DNS 信息测量

dig是著名的 DNS 软件 Bind 提供的 DNS 分析和测量工具。dig 可以查询 DNS 包括 NS 记录，A 记录，MX 记录等相关信息的工具，利用它可以进行 DNS 测量和分析。 

安装 dig 命令并进行以下查询和测量 

dig xju.edu.cn 

dig xju.edu.cn @8.8.8.8 

dig mx xju.edu.cn 

dig ns xju.edu.cn @8.8.8.8 

dig www.xju.edu.cn +trace 

dig edu.cn +dnssec @8.8.8.8

dig edu.cn +dnssec @114.114.114.114

**参考资料：**

https://www.isc.org/bind/ https://www.cnblogs.com/machangwei-8/p/10353216.html

**dig 安装**

​	Debian 系统 apt-get install dnsutils 

​	Centos 系统 yum install bind-utils

![img](https://kimi.moonshot.cn/api/sign-obj/kfs%2F1%2F2%2F2025-05-16%2Fd0jamjtr1r8p1mg5vfh0/image.png?sig=GlKQJvSPmNemSIsQe9--kjz69JPFHUU2IzMJM08j0Sk=&t=p)

解决办法：删除yum.repos.d目录下所有文件然后使用阿里云的镜像站点下载 CentOS 7 的 YUM 源配置文件

```
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo
```
