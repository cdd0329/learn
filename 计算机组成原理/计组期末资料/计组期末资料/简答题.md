3. 计算机硬件系统包括哪些部分？P6-8

```
CPU、主存储器、外存储器、输入/输出设备、总线、接口
1、CPU即中央处理器，是硬件系统的核心部件，负责读取并执行指令，也就是执行程序
2、主存储器用来存放需要执行的程序及需要处理的数据，能由CPU直接读出或写入
3、外存储器用来存放那些需要联机存放，但暂不执行的程序和数据，当需要运行它们时再由外存调入主存
4、输入设备用来将计算机外部的信息输入计算机；输出设备将计算机的处理结果以我们能看得懂的形式输出
5、总线是指一组能为多个部件分时共享的信息传输线
6、接口是指系统的（软件或硬件）组件和其他组件的交互点
```

7. 什么是组合逻辑控制器？什么是微程序控制器？试比较它们的优缺点。P89.P101

```
组合逻辑控制器：指产生控制信号即微命令的部件是用组合逻辑线路来实现的控制器。
   优点：速度快
   缺点：（1）设计较凌乱，效率较低，检查调试较困难。
        （2）不易修改与扩展。
微程序控制器：指将程序技术引入到CPU的构级，即采用微程序控制方式来产生微命令的控制器。
   优点：设计比较规整，易于修改补充。
   缺点：速度较组合逻辑控制器稍慢。
   
-------------------------------------------------------------------------------------------------------
计算机的控制器根据产生控制信号方式的不同，可分为组合逻辑控制器和微程序控制器。组合逻辑控制器由组合逻辑线路（逻辑门电路）产生控制信号，微程序控制器由微程序产生的控制信号。相较于微程序控制器，组合逻辑控制器速度较快，但是设计效率低、检查调试复杂、修改扩展困难
```

8. 实模式下逻辑地址分别由哪两部分组成，并简述过程（P131）

```
在实模式下，逻辑地址由两部分组成：段地址（Segment Address）和偏移地址（Offset Address）。
段地址（Segment Address）：段地址是一个16位的值，用于指示内存中的段（Segment）。每个段的长度固定为64KB（65536字节）。段地址乘以16后得到一个20位的物理地址，作为该段在内存中的起始位置。
偏移地址（Offset Address）：偏移地址是一个16位的值，表示从段的起始位置开始的偏移量。通过偏移地址，可以定位到段内部的具体字节或者单元。
将段地址左移4位（乘以16），然后与偏移地址相加，可以得到最终的20位逻辑地址。这个逻辑地址可以直接用于访问内存中的数据。
简要描述过程如下：
程序使用段寄存器（如CS、DS、ES等）存储段地址。
程序通过偏移寄存器（如IP、BX、DI等）存储偏移地址。
通过段地址左移4位并与偏移地址相加，生成20位逻辑地址。
使用逻辑地址访问对应的内存单元。
```

11. Cache有哪3种基本映像方式，分别是什么？各自的主要特点是什么？（P277）

```
1、直接映像：主存中每一个块只能复制到某一个固定的cache块中
2、全相连映像：主存的每一块可映像到cache的任一块
3、组相连映像：折中方案，主存与cache都分组，主存中一个组的块数和cache中的分组数相同
------------------------------------------------------------------------------------------------------
直接映射（Direct Mapping）：
每个主存块（Cache Line）只能映射到缓存的固定位置。
地址只与缓存行号相关，与主存地址进行某种映射关系计算。
存取速度快，实现简单，硬件开销低。
缓存冲突概率高，可能导致较多的缓存未命中。

全相连映射（Fully Associative Mapping）：
主存块可以映射到缓存的任意位置，无固定映射规则。
地址直接作为比对输入，与所有缓存行进行比对。
命中率高，减少了缓存冲突，提高了缓存性能。
实现复杂，硬件开销较高。

组相连映射（Set Associative Mapping）：
主存块被分成若干组，每组内部采用全相连映射方式。
每个主存块只能映射到某一组内的任意位置。
介于直接映射和全相连映射之间的折衷方案。
提供了一定程度的灵活性，缓解了直接映射中的冲突问题。
```

12. 简述中断和DMA模式的过程。（P321、336）

```
中断的过程一般可划分为几个阶段：中断请求、中断排忧、中断响应、中断处理和中断返回

中断是一种机制，允许外设和CPU之间的通讯，让CPU在需要时注册一个中断处理程序，当外设发出信号时，CPU会停止当前正在进行的任务，并执行中断处理程序。

DMA（直接内存访问）是一种机制，它使某些设备（如硬盘驱动器或网卡）能够直接访问系统内存，而无需参与CPU。 DMA控制器负责在需要时将数据从设备传输到内存，或将数据从内存传输到设备，无需使CPU参与传输过程。这使得操作系统可以使用多个设备同时执行多个I/O操作。
```
