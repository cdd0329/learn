### 第一小问 

Dao

本题中主要干事情是获取数据库中的数据并保存到动态数组中

```java
     //定义一个返回类型为List类型的方法
    // List<Course>表示这个列表中的每一个元素均是 Course 对象
    //因为在service中用的时候我们想要直接那ArrayList动态数组类型所以返回值类型是List<>
    // Course 这个名字是不确定考试的时候提供给我们是bean，bean中有这个类，
public List<Course> list() {
	String sql = "select * from course";
	List<Course> list = new ArrayList<>();
     //连接数据库
	Connection conn = DBUtil.getConn();
	Statement state = null;
	ResultSet rs = null;
    //关联conn对象
    state = conn.createStatement();
    //利用Statement对象来执行sql查询语句
    rs = state.executeQuery(sql);
    Course bean = null;
    while (rs.next()) {
        //我在这里演示的是只有两列的表，考试的时候可能是三列或四列，也会给列的名字
        //这里所编写的列的名字是id 、name 、teacher 、classroom
        //这里就是表中的列来读取数据
        int id = rs.getInt("id");
        String name = rs.getString("name");
        String teacher = rs.getString("teacher");
        String classroom = rs.getString("classroom");
        //这里的 Course()方法就是 bean 中的方法考试的时候肯定会给这个方法的名字到时候改一下就行
        // Course 对象存到list动态数组中，最后会返回这个list
        bean = new Course(id, name, teacher, classroom);
        list.add(bean);
    //关闭资源，这也是必须要写
    DBUtil.close(rs, state, conn);	
	return list;
}
```
